it should be possible to delete conversations. Currently, we show a select box on the action popup where the user can select the active conversation.

When the user is in an ongoing or finished conversation, show a trash can next to the select box. this deletes the current conversation and goes to the next in the list (down, or when at last, remain at last conversation in the list).

When the conversation is running, the delete should be disabled, include in the tooltip why delete is not possible (delete not possible cause conversation is running)
