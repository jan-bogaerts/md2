# MD² 0.9.0

## New features

* Track agent tasks directly in conversations.
* Choose the agent, model, and reasoning settings for sequences.
* Open projects from a command or the Windows taskbar.
* View active schedules from the status bar.

## Improvements and fixes

* Create, arrange, and start card sequences more easily.
* Sequence worktrees, ready states, restarts, and scheduled prompts now work more reliably.
* Search stays consistent when closed or resized and now has clear buttons.
* Markdown indentation and placeholder menus are preserved correctly.
* Pinned and continued conversations now remain available and up to date.
* Agent conversations continue correctly after questions and show result notifications accurately.
* Worktree integration and imported-card saving are more reliable.
* Statistics keep consistent colors when filters change.
* Sentry imports handle large batches more reliably.
* Diagram editing and action prompts are more responsive and reliable.
