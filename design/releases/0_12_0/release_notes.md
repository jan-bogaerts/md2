# MD² 0.12.0

## New features

* View and edit JSON files in a dedicated editor.
* Browse changed files in tabs and add inline review comments.
* Choose whether to keep a local project's design folder out of Git.
* Open email links in your default email app.
* Choose which actions to show, including those with conversation history.
* Configure diagram items using legend labels.
* Select nested lists and starting positions for for-each actions.
* Track for-each progress, resume from a stopped position, and advance step by step.
* Control how often for-each actions compact or start a new conversation.
* Include the full current record in a for-each prompt.

## Improvements and fixes

* Improved JSON editing, worktree operations, and feedback during project integration.
* Remember a separate window size for code diffs.
* Updated documentation and improved Markdown editor responsiveness.
* Fixed issues with project switching, file links, action conversations, and for-each runs.
* File suggestions now reflect added, moved, and deleted files.
