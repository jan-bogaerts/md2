# MD² 0.4.0

## New features

- Attach files to cards and agent prompts.
- Import Sentry issues as bug cards.
- Paste images directly into card editors.
- Indent and outdent lists on small screens.
- See Claude usage limits in the status bar.
- Track project and account usage over time.
- View project activity and usage statistics.
- See project status on small screens.

## Improvements

- See stable, accurate token usage totals.
- Review worktree changes before saving them.
- See live context usage at the end of conversations.
- Create cards more quickly from the small-screen menu.
- Read context usage from a compact circular indicator.
- Find attachment controls in more convenient locations.
- Search with clearer controls and result counts.
- Use more space for editing on small screens.
- See matching text highlighted in search results.
- Create cards from a simpler dialog.
- Open action popups on the most relevant action.
- Read low context usage more clearly.
- Fit more options into compact menus.
- Open projects from a clearer source selector.
- Compare activity, agents, models, and usage in improved charts.
- See one clear file-change total in action summaries.
- Load statistics faster.
- Use less space for saved activity.
- Get reliable Claude usage updates with custom setups.

## Fixes

- Editor search now waits until you submit the query.
- Placeholders now resolve in every agent message.
- Conversation timers now exclude time spent waiting.
- Merge-conflict agents now open without card errors.
- Claude responses no longer appear twice around questions.
- Agent input remains available while waiting for a response.
- File attachments now insert correctly in new cards.
- Project status no longer overlaps navigation on small screens.
- Sentry connections and issue imports now work correctly.
- Cancelling a new card no longer duplicates prompts or blocks input.
- Connected devices now recover cleanly after reconnecting.
- Card conversations now load without missing-activity errors.
- The new-card editor now fills the available screen height.
- Token totals now initialize correctly for existing projects.
- Added and deleted line counts now display correctly.
- Actions on connected devices now recover correctly after interruptions.
- Added and deleted files now count toward file changes.
- Run buttons now show the correct state after opening a project.
- Codex sub-agents no longer change the main action state incorrectly.
- Statistics charts now align and compare providers correctly.
- Claude context usage now appears in conversations.
