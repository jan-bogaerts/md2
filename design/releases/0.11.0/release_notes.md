# MD² 0.11.0

## New features

* Run an agent action for every item in an attached JSON file.
* Find and replace text in the Markdown editor.
* Search automatically after you pause typing.

## Improvements and fixes

* Diagrams now save automatically with the rest of the project.
* Add child diagrams from selected items while editing a diagram.
* Edit and save regular Markdown files reliably.
* Resize the prompt area in action popups again.
* Compact conversations reliably after stopping and restarting the app.
