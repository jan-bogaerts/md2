# MD² 0.2.0

## New features

- See the number of changed lines in agent file updates.
- Copy a card’s full or repository-relative file path.
- Resolve merge conflicts with external tools or agents.
- Use `{{this-card}}` in action prompts.
- Insert placeholders directly in the action input.
- Open action popups full-screen by default on mobile.
- Create custom actions from one simplified option.
- View grouped tool calls in a cleaner conversation box.
- See shorter, clearer approval requests.
- Keep unnecessary diagnostics out of conversations.
- Hide suggested responses while an approval is open.
- Resize the file selector and keep its chosen size.
- Load released-card activity only when needed.
- Use one clear permission setting across agents.
- See simpler action controls for each conversation state.
- Choose the scope for token, change, and line totals.
- Move, resize, and open multiple card popups.
- Choose agent models and security settings more easily.
- Get more conversation space from a compact action input.
- Automatically recover older or damaged activity data.

## Fixes

- Agent responses no longer appear twice.
- Agent selections are remembered when reopening an action.
- Switching agents keeps the existing conversation.
- Existing conversations no longer receive unwanted prefilled text.
- Merge-conflict agents now open in the standard action popup.
- Save status stays synchronized across connected app views.
- Markdown files opened in list view now show their toolbar.
- Cards move to the correct column after automatic status changes.
