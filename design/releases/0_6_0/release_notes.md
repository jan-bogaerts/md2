# MD2 0.6.0

## New features

* View, explore, and run actions from interactive diagrams.
* Edit diagrams and review changes before saving a copy.
* Format diagram items, connections, spacing, and text.
* Zoom and pan saved and edited diagrams independently.
* Emphasize related diagram items and connections.
* Use diagram legends and dedicated diagram menu controls.
* Search within action conversations.
* Copy, split, and save conversation messages.
* Insert emojis and other special characters in Markdown.
* Import Sentry issues from the Run menu.
* Filter statistics by release.
* View detailed time breakdowns for agent activity.
* Restore unanswered agent questions after reopening the app.
* Close full-screen popups with the browser Back button on small screens.
* Install available app updates from an in-app notification.

## Improvements and fixes

* Improved diagram layout, sizing, navigation, menus, scrolling, and performance.
* Diagrams can now contain any number of items and connections.
* Improved project opening and folder setup dialogs.
* Improved agent question layout, resizing, and custom answers.
* Improved code blocks in action conversations.
* Improved token counts and Claude usage reporting.
* Improved project-agent status indicators and action states.
* Improved small-screen board column counts.
* Improved Sentry-imported card titles.
* Fixed command text changing before an action runs.
* Fixed unwanted prompt refills and duplicate merge-conflict errors.
* Fixed file suggestions appearing too far from the cursor.
* Fixed copying paths from remotely connected devices.
* Improved remote reconnection reliability.
* Improved worktree removal and recovery.
* Improved card opening speed and emoji picker performance.
