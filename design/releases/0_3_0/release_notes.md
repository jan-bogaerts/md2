# MD² 0.3.0

## New features

- Search text directly in the Markdown editor.
- See queued steering prompts and send them immediately.
- See how much conversation context is in use.
- Find agent-reported commits in card history.
- See the project name in the app window title.
- Watch token usage update while an agent is running.
- Open local folders and GitHub repositories from one dialog.
- Get notified when a new app version is available.
- Browse a more compact, easier-to-scan project tree.
- Copy Markdown as formatted text or plain text.
- Use action controls more easily on small screens.
- Enjoy a steadier chat view during live updates.
- Review completed reasoning that contains text.
- Restore the app window's previous size and position.
- Share the app with other devices using a stable address.
- Resize expanded action popups.
- Update Codex directly when a newer version is required.
- Use the active cards folder in action prompts.
- Change a card's state from its popup.
- See context usage below the conversation.
- Benefit from improved automatic error reporting.

## Improvements

- Add new cards faster.
- Use clipboard commands from the Markdown editor's context menu.

## Fixes

- Worktree status now updates correctly on connected devices.
- Agent settings now work correctly on connected devices.
- Action popups now open reliably after connecting.
- Active conversations no longer revert to older content.
- Popups now fit the available screen height on mobile.
- Pending edits are saved before the app closes.
- Creating a card with Ctrl+Enter no longer adds an extra line.
- Renamed actions now work immediately.
