# MD² 0.10.0

## New features

* Manage multiple Codex and Claude accounts and choose an account for each action, run, or schedule.
* Track running task progress from card popups; completed task lists now start collapsed.
* Use the actions-folder placeholder in prompts.
* Edit diagram titles and subtitles directly from the breadcrumb bar.
* Copy formatting between diagram items with the new format painter.
* Turn reviewed diagram changes into implementation cards.

## Improvements and fixes

* Diagram editing now has better keyboard controls, selection, labels, legends, colors, and add-item dialogs.
* Switch between card popups with Ctrl+Tab and enjoy more consistent keyboard shortcuts throughout the app.
* Agent tasks, scheduled follow-ups, sequences, and conversation finishing now work more reliably.
* Agent usage, task activity, and changes from parallel work are tracked more accurately.
* Worktree integration and discarding changes now provide clearer, more reliable handling of pending files.
* Cards and pasted images load reliably after reopening.
* Project background colors are applied to the correct views immediately after saving.
* Action prompts and project-folder setup have clearer layouts and respond more smoothly.
